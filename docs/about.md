## 🎯 Purpose of this Portfolio

This project was built to document an exhaustive, white-box security review of the **OWASP Juice Shop** vulnerable web application. 

Key objectives demonstrated in this repository:
1. **Systematic Vulnerability Assessment:** Applying standard penetration testing methodologies (OWASP WSTG) from reconnaissance to exploitation.
2. **Technical Depth:** Going beyond standard CTF flags to locate flawed code statements inside the application codebase and explain why the vulnerability exists.
3. **Actionable Remediasi:** Formulating defensive patches and secure coding patterns directly usable by software engineering teams.
4. **Professional Documentation:** Producing clear, reproducible, and executive-ready vulnerability reports.
